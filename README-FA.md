# فیت‌پلاس — نسخه بازسازی‌شده برای GitHub Pages

## فایل‌ها
- `index.html`: برنامه اصلی فیت‌پلاس
- `manifest.json`: تنظیمات نصب PWA
- `service-worker.js`: کش پوسته برنامه برای دسترسی آفلاین پس از اولین بارگذاری موفق
- `icons/icon-512.svg`: آیکن برنامه

## جایگزینی در GitHub
1. در مخزن GitHub وارد شوید.
2. از دکمه **Add file → Upload files** استفاده کنید.
3. این چهار فایل/مسیر را در ریشه مخزن آپلود کنید؛ پوشه `icons` را هم با فایل داخل آن حفظ کنید.
4. اگر GitHub پرسید فایل‌ها جایگزین شوند، تأیید کنید و سپس **Commit changes** را بزنید.
5. در Settings → Pages بررسی کنید که سایت از شاخه و پوشه درست منتشر می‌شود.

## نکته‌های مهم
- برنامه اطلاعات تمرین و پروفایل را در `localStorage` همان مرورگر/دستگاه ذخیره می‌کند؛ این اطلاعات به‌طور خودکار بین دستگاه‌ها همگام نمی‌شوند.
- حالت آفلاین پس از باز شدن موفق سایت و نصب Service Worker فعال می‌شود و به HTTPS (مانند GitHub Pages) نیاز دارد.
- برای جلوگیری از از دست رفتن نسخه، پیش از جایگزینی فایل‌های فعلی را از طریق Download ZIP نگه دارید.
